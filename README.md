An entry for the make.fun contest "Funniest Time Machine Warning Label" — the funniest one-line warning label for a time machine in 120 characters or fewer. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes exactly one line to `/output/entry.txt`: a safety notice warning the traveller not to meet their own past self, because that self owes them money, knows it, and will pretend not to recognise them — the classic duplicate-self paradox, delivered with a straight face.
